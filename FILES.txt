USAGE:

1. Start Server:
   $ cd altcha-server
   $ docker-compose up -d

2. Test Server:
   $ bash altcha-server/deploy.sh

3. Install Plugin:
   $ cp -r altcha-wordpress-plugin /path/to/wordpress/wp-content/plugins/

4. Activate & Configure:
   - WordPress Admin → Plugins → Activate "Altcha Protection"
   - Settings → Altcha Protection
   - Enter server URL: http://localhost:8080
   - Click "Fetch Public Key"
   - Enable protections
   - Save Settings


CONFIGURATION:

Environment Variables (altcha-server/.env):
  ALTCHA_SECRET=<your-secret-key>           # HMAC signing key
  ALTCHA_DIFFICULTY_DEFAULT=2               # PoW difficulty (1-4)
  ALTCHA_CORS_ORIGIN=https://yourdomain.com # CORS restriction
  PORT=8080                                 # Server port

WordPress Settings:
  Altcha Server URL: http://localhost:8080
